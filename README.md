# releases
Approved releases of the Naetive command for users' computers. Each change here needs the owner's approval before computers install it.

## Security's approval is asked again here

The release check on every proposal asks naetive.ai whether the proposal's review approves exactly its platform
commit for exactly its pieces, the same question release-propose asks. That answer includes the founder's own yes:
**the founder's newest answer on the release job must still be a yes to this review when the pull request is
checked.** A later "Not yet", or a yes to another review, makes the check fail; answer yes again (or re-run the
check after the right yes) before merging.
